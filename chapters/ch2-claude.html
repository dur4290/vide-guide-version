Ch2. Claude Code 시작하기

Chapter 2 ⏱ 약 20분

이 챕터에서는 VSCode 안에서 Claude Code를 바로 쓸 수 있도록 Claude Code 확장을 설치하고 로그인합니다. 설치가 끝나면 VSCode 안에서 AI와 대화하며 파일을 만들고 수정할 수 있어요.

⚠️
Claude Pro 구독이 필요합니다
claude.ai에서 Pro 구독(월 약 ₩30,000)이 되어 있어야 합니다. 아직 구독하지 않았다면 먼저 구독하고 돌아오세요.

1. Claude Code 확장 설치하기

1

VSCode 확장 탭 열기

VSCode 왼쪽의 퍼즐 모양 아이콘(확장 프로그램)을 클릭하거나 Ctrl + Shift + X를 누르세요.

2

Claude Code 설치

검색창에 Claude Code를 입력하고, Anthropic에서 제공하는 확장을 설치하세요.

2. VSCode에서 Claude Code 열기

확장 설치가 끝나면 VSCode 안에서 Claude Code 패널을 열고 Claude Pro 계정으로 로그인합니다.

1

Claude Code 패널 열기

VSCode 왼쪽 사이드바의 Claude Code 아이콘을 클릭하세요. 아이콘이 안 보이면 Ctrl + Shift + P를 누르고 Claude Code를 검색해 열 수 있습니다.

VSCode를 완전히 닫았다가 다시 열어보세요.

그래도 없으면 명령 팔레트(Ctrl + Shift + P)에서 Developer: Reload Window를 실행한 뒤 다시 확인하세요.

2

로그인하고 첫 대화 테스트
