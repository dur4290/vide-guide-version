Ch3. Git 기초

Chapter 3 ⏱ 약 20분

Git은 코드의 변경 내역을 기록하는 도구입니다. 게임의 "세이브 포인트"처럼 작업 중간중간 저장해두면 실수해도 되돌릴 수 있어요. 이 챕터에서는 Git의 기본 개념을 배우고, 실습에 쓸 워크스페이스를 ZIP으로 내려받겠습니다.

1. Git 설치하기

1

Git 다운로드

git-scm.com에 접속해서 Windows용 Git을 다운로드하세요.

2

내 이름과 이메일 등록

Git은 변경사항을 기록할 때 누가 작업했는지 표시합니다. 내 정보를 등록해봅시다.

VSCode 터미널을 열고 아래 명령어를 실행하세요. 홍길동과 email@example.com을 본인 정보로 바꾸세요:

git config --global user.name "홍길동"
git config --global user.email "email@example.com"
git config --global user.name
위 명령어를 실행하면 등록한 이름이 출력됩니다.

2. GitHub 계정 만들기

GitHub는 Git으로 관리하는 코드를 인터넷에 올려두는 공간입니다. 내 작업물을 클라우드에 백업하고 다른 사람과 공유할 수 있어요.

1

GitHub 가입

github.com에 접속해서 Sign up을 클릭하고 계정을 만드세요.

💡
username은 나중에 포트폴리오 URL로 사용됩니다. github.com/내username 형태가 되니 신중하게 정하세요.

3. 내 실습 폴더 만들고 VSCode로 열기

학생 배포용 워크스페이스를 ZIP 파일로 내려받은 뒤 VSCode로 열겠습니다. 이 폴더에는 Claude Code에게 내 상황을 설명하는 CLAUDE.md와 자주 쓰는 슬래시 커맨드들이 미리 세팅되어 있어요.

1

학생 배포용 저장소 열기

아래 링크를 열어주세요.

👉 github.com/dur4290/vibe-coding-guide

2

Download ZIP으로 내려받기

GitHub 화면에서 초록색 Code 버튼을 누른 뒤 Download ZIP을 클릭하세요.

💡
다운로드가 끝나면 ZIP 파일을 압축 해제하세요. 압축을 푼 폴더 이름이 길게 보이면 vibe-workspace처럼 짧게 바꿔도 됩니다.
3

VSCode에서 워크스페이스 폴더 열기

VSCode에서 File > Open Folder를 선택하고, 방금 압축을 푼 워크스페이스 폴더를 여세요. 폴더 위치는 바탕화면이나 문서 폴더처럼 찾기 쉬운 곳을 추천합니다.

왼쪽 파일 탐색기에 CLAUDE.md, README.md, projects/, notes/ 폴더가 보이면 성공입니다.

4

/start 커맨드로 워크스페이스 개인화

Claude Code 입력창에 아래를 입력하면 내 이름과 목표를 CLAUDE.md에 자동으로 저장해줍니다.

/start
💡
한 번만 하면 됩니다. 이후 Claude가 대화할 때마다 내 정보를 기억해요.

4. Git 기본 명령어 배우기

Git을 쓸 때 반복해서 사용하는 명령어 세 가지를 배워봅시다.

1

git status — 현재 상태 확인

어떤 파일이 변경됐는지 확인하는 명령어입니다.

git status
2

git add — 저장할 파일 선택

변경된 파일을 "저장 대기 상태"로 올리는 명령어입니다. .은 모든 파일을 의미해요.

git add .
3

git commit — 세이브 포인트 만들기

변경사항을 저장하는 명령어입니다. -m 뒤에 어떤 변경이었는지 메모를 남겨요.

git commit -m "CLAUDE.md 수정: 내 이름 추가"

5. /save로 GitHub에 첫 저장하기

이제 ZIP으로 받은 워크스페이스를 내 GitHub 저장소에 연결해봅니다. 이렇게 해두면 앞으로 /save만 입력해도 작업 내용을 GitHub에 저장할 수 있어요.

💡
왜 Git 커밋을 하나요?
Git 커밋은 작업의 세이브 포인트입니다. 어떤 파일을 언제, 왜 바꿨는지 기록하고, 필요하면 예전 상태로 돌아갈 수 있게 해줍니다. GitHub에 push하면 내 컴퓨터 밖에도 백업이 생겨서 다른 PC에서도 이어서 작업할 수 있어요.
1

GitHub에 빈 저장소 만들기

GitHub에서 새 저장소를 만드세요. 저장소 이름은 first-vibe-coding처럼 짧고 알아보기 쉽게 정합니다.

  1. GitHub 오른쪽 위 + 버튼을 누르세요
  2. New repository를 선택하세요
  3. Repository name에 first-vibe-coding을 입력하세요
  4. Add a README file은 체크하지 마세요
  5. Create repository를 누르세요
⚠️
README를 체크하면 처음 push할 때 충돌이 날 수 있습니다. 빈 저장소로 만든 뒤 현재 워크스페이스를 올리는 편이 가장 쉽습니다.
2

워크스페이스와 GitHub 저장소 연결

새 저장소 화면에 보이는 주소를 복사하세요. 보통 아래처럼 생겼습니다. 

https://github.com/내아이디/first-vibe-coding.git

Claude Code 입력창에 아래처럼 요청하세요. 주소 부분은 본인 주소로 바꾸면 됩니다.

이 워크스페이스를 내 GitHub 저장소에 연결해줘.

저장소 주소:
https://github.com/내아이디/first-vibe-coding.git

해야 할 일:
- git init이 안 되어 있으면 실행
- 기본 브랜치는 main으로 설정
- remote origin을 위 저장소 주소로 연결
- 아직 커밋하지 말고 연결 상태만 확인
3

/save로 첫 커밋과 push

이제 Claude Code 입력창에 아래를 입력하세요.

/save 첫 워크스페이스 설정 저장

Claude가 변경된 파일을 확인하고, 보안 문제가 없는지 본 뒤, 커밋 메시지를 확인하고 GitHub에 올려줍니다.

💡
이후 Ch4와 Ch5에서 파일을 만들거나 수정한 뒤에도 /save를 다시 입력하면 새 작업 내용을 같은 저장소에 계속 저장할 수 있습니다.
