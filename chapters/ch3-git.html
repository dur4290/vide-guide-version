Ch3. Git 기초

Chapter 3 ⏱ 약 30분

Git은 코드의 변경 내역을 기록하는 도구입니다. 게임의 "세이브 포인트"처럼 작업 중간중간 저장해두면 실수해도 되돌릴 수 있어요. 이 챕터에서는 Git을 설치하고, 실습에 쓸 폴더를 GitHub에서 내려받겠습니다.

1. Git 설치하기

1

Git 다운로드

git-scm.com에 접속해서 Windows용 Git을 다운로드하세요.

2

내 이름과 이메일 등록

Git은 변경사항을 기록할 때 누가 작업했는지 표시합니다. 내 정보를 등록해봅시다.

VSCode 터미널을 열고 아래 명령어를 실행하세요. 홍길동과 email@example.com을 본인 정보로 바꾸세요:

git config --global user.name "홍길동"
git config --global user.email "email@example.com"
git config --global user.name
위 명령어를 실행하면 등록한 이름이 출력됩니다.

2. GitHub 계정 만들기

GitHub는 Git으로 관리하는 코드를 인터넷에 올려두는 공간입니다. 내 작업물을 클라우드에 백업하고 다른 사람과 공유할 수 있어요.

1

GitHub 가입

github.com에 접속해서 Sign up을 클릭하고 계정을 만드세요.

💡
username은 나중에 포트폴리오 URL로 사용됩니다. github.com/내username 형태가 되니 신중하게 정하세요.

3. 내 실습 폴더 만들고 VSCode로 열기

학생 배포용 워크스페이스를 내 GitHub 계정으로 복사한 뒤 VSCode로 열겠습니다. 이 폴더에는 Claude Code에게 내 상황을 설명하는 CLAUDE.md와 자주 쓰는 슬래시 커맨드들이 미리 세팅되어 있어요.

1

학생 배포용 저장소 열기

아래 링크를 열어주세요.

👉 github.com/dur4290/vibe-coding-guide

2

내 GitHub 저장소로 복사

GitHub 화면에서 Use this template 또는 Fork를 눌러 내 계정에 새 저장소를 만드세요.

⚠️
Download ZIP은 쓰지 마세요. ZIP으로 받으면 나중에 /save가 내 GitHub 저장소로 올리지 못할 수 있어요.
3

VSCode에서 내 저장소 열기

VSCode에서 Clone Git Repository를 선택하고, 방금 만든 내 저장소 주소를 붙여넣으세요. 폴더 위치는 바탕화면이나 문서 폴더를 추천합니다.

왼쪽 파일 탐색기에 CLAUDE.md, README.md, projects/, notes/ 폴더가 보이면 성공입니다.

4

/start 커맨드로 워크스페이스 개인화

Claude Code 입력창에 아래를 입력하면 내 이름과 목표를 CLAUDE.md에 자동으로 저장해줍니다.

/start
💡
한 번만 하면 됩니다. 이후 Claude가 대화할 때마다 내 정보를 기억해요.

4. Git 기본 명령어 배우기

Git을 쓸 때 반복해서 사용하는 명령어 세 가지를 배워봅시다.

1

git status — 현재 상태 확인

어떤 파일이 변경됐는지 확인하는 명령어입니다.

git status
2

git add — 저장할 파일 선택

변경된 파일을 "저장 대기 상태"로 올리는 명령어입니다. .은 모든 파일을 의미해요.

git add .
3

git commit — 세이브 포인트 만들기

변경사항을 저장하는 명령어입니다. -m 뒤에 어떤 변경이었는지 메모를 남겨요.

git commit -m "CLAUDE.md 수정: 내 이름 추가"

5. /save — GitHub에 올리기

git add → commit → push를 매번 직접 입력하는 대신, 워크스페이스에는 /save 커맨드가 미리 준비되어 있어요.

1

/save 사용법

Claude Code 입력창에 아래를 입력하세요:

/save

Claude가 자동으로 아래 순서로 처리합니다:

  1. API 키 같은 민감 정보가 포함됐는지 보안 확인
  2. 커밋 메시지 확인
  3. 내 GitHub 저장소에 push
💡
/save는 보안 검사 후 git add . + git commit + git push를 도와주는 단축 커맨드예요.
