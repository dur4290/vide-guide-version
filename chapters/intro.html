이 가이드에서 뭘 배우나요?

이 가이드를 끝내면 AI에게 원하는 걸 말해서 실제로 돌아가는 프로그램을 만들 수 있게 됩니다. 코딩 문법을 외울 필요 없어요. AI가 코드를 짜주고, 여러분은 무엇을 만들지 방향을 잡으면 됩니다. 이걸 바이브코딩이라고 부릅니다.

💡
바이브코딩이 뭔가요? AI(Claude Code)에게 원하는 기능을 자연어로 설명하면 AI가 코드를 생성해줍니다. 여러분은 결과를 보고 피드백만 주면 됩니다. 코드를 직접 짜는 게 아니라 방향을 잡는 것이 핵심이에요.

가이드를 마치면 이런 걸 할 수 있어요:

  • ✅ 반복적인 파일 정리를 자동화하는 스크립트 만들기
  • ✅ Claude Code로 아이디어를 코드로 바꾸기
  • ✅ 만든 프로그램을 워크스페이스 폴더에 저장하고 관리하기
  • ✅ 공모전에서 아이디어를 빠르게 프로토타이핑하기

챕터 개요

1

개발 환경 설정 약 20~40분

VSCode(코드 에디터)와 Python이 준비되어 있는지 확인하고, 없을 때만 설치합니다.

2

Claude Code 시작하기 약 30분

AI 코딩 도구인 Claude Code를 설치하고 첫 대화를 나눠봅니다.

3

Git 기초 약 30분

코드 버전 관리 도구 Git을 가볍게 배우고, 실습 폴더를 ZIP으로 내려받습니다.

4

마크다운 문서 만들기 약 35분

Claude Code와 함께 마크다운 보고서를 만들고, 워크스페이스 안에 자동 저장하는 흐름을 익힙니다.

5

실습 프로젝트 약 60분

Claude Code를 이용해 파일 정리 자동화 스크립트를 실제로 만들어봅니다.
