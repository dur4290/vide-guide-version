Ch5. 실습 — 파일 정리 자동화

Chapter 5 ⏱ 약 60분

드디어 진짜 프로젝트를 만들 차례입니다! 🚀
다운로드 폴더 안에 파일이 섞여있어서 불편했던 경험이 있나요? 이번에 Claude와 함께 파일들을 확장자별로 자동 분류하는 Python 스크립트를 만들어봅니다. 실제 다운로드 폴더를 건드리기 전에 테스트 폴더에서 먼저 안전하게 연습합니다.

💡
이번 챕터에서 만드는 것
스크립트를 실행하면 테스트 폴더 안의 파일들이 자동으로 분류됩니다:
  • 📄 PDF → 문서/ 폴더
  • 🖼 이미지 (jpg, png 등) → 사진/ 폴더
  • 🎵 음악 (mp3 등) → 음악/ 폴더
  • 📦 그 외 → 기타/ 폴더

1. 실습 폴더 준비하기

1

워크스페이스 폴더를 VSCode로 열기

Ch3에서 클론한 워크스페이스 폴더가 닫혀있다면 파일 > 폴더 열기로 다시 열어주세요.

2

VSCode에서 Claude Code 열기

왼쪽 사이드바에서 Claude Code 아이콘을 클릭해서 패널을 여세요.

Claude가 워크스페이스 폴더 폴더를 인식하고 CLAUDE.md를 읽어들입니다.

2. 테스트 폴더 만들고 스크립트 요청하기

코드를 알 필요 없어요 — 먼저 안전한 테스트 폴더를 만들고, 그 폴더만 정리하도록 요청하면 됩니다.

1

테스트 폴더 만들기

Claude 입력창에 아래 내용을 입력하세요 (그대로 복사해도 됩니다):

바탕화면에 'test-downloads' 폴더를 만들고,
안에 테스트용 빈 파일을 6개 정도 만들어줘.

예시:
- report.pdf
- photo.jpg
- screenshot.png
- music.mp3
- memo.txt
- data.csv
2

테스트 폴더 정리 스크립트 요청

이제 Claude에게 아래처럼 요청하세요:

방금 만든 test-downloads 폴더를 정리해주는 Python 스크립트를 만들어줘.

조건:
- 파일 이름은 반드시 organize.py로 저장
- PDF 파일은 '문서' 폴더로 이동
- 이미지 파일(jpg, jpeg, png, gif, webp)은 '사진' 폴더로 이동
- 음악 파일(mp3, wav, flac)은 '음악' 폴더로 이동
- 그 외 파일은 '기타' 폴더로 이동
- 폴더가 없으면 자동으로 만들어줘
- 실제 다운로드 폴더는 건드리지 말고 test-downloads 폴더만 대상으로 해줘
- 각 줄에 주석으로 설명도 달아줘
⚠️
처음부터 실제 다운로드 폴더를 정리하지 마세요. 테스트 폴더에서 성공한 뒤에만 실제 폴더 적용을 요청하는 것이 안전합니다.
3

생성된 코드 확인하기

Claude가 워크스페이스 안에 organize.py 파일을 만들어줄 거예요. VSCode 왼쪽 파일 탐색기에서 열고, 정리 대상 경로가 test-downloads인지 확인하세요.

Claude에게 이렇게 물어보세요: 
이 코드를 초보자도 이해할 수 있게 한 줄씩 설명해줘

3. 실제로 실행해보기

⚠️
실행 전 확인!
스크립트가 실행되면 파일이 실제로 이동됩니다. 지금은 test-downloads 폴더만 대상으로 해야 합니다.
1

스크립트 실행하기

Claude에게 이렇게 요청하세요:

organize.py를 실행해줘

Claude가 직접 실행해주고 결과를 알려줍니다. 테스트 폴더를 열어보면 파일들이 분류되어 있을 거예요! 🎉

오류 메시지를 복사해서 Claude에 붙여넣고 이렇게 물어보세요: 
이 오류가 났어. 왜 그런지 설명하고 고쳐줘:
[오류 메시지 붙여넣기]
2

실제 다운로드 폴더에 적용할지 결정

테스트가 성공했을 때만 Claude에게 이렇게 요청하세요:

테스트 폴더에서는 잘 됐어.
이제 실제 다운로드 폴더에 적용하기 전에,
어떤 파일이 어디로 이동될지 먼저 미리보기로 보여주는 기능을 추가해줘.
내가 확인한 뒤에만 실제 이동되게 해줘.
💡
실제 파일을 옮기는 자동화는 항상 미리보기와 확인 단계를 넣는 습관이 좋습니다.

기본 버전이 잘 됐나요? 이제 더 좋게 만들어봅시다. 개선을 요청하는 것도 바이브코딩의 핵심이에요!

1

개선 요청 예시

아래 중 하나를 골라서 Claude에 요청해보세요:

5. 완성본 저장하기

1

/save로 변경사항 저장

VSCode 왼쪽 파일 탐색기에서 오늘 만든 organize.py 파일이 보이면 됩니다. Ch3에서 GitHub 저장소를 연결했다면, 이제 이 변경사항도 GitHub에 올릴 수 있습니다. 

/save 파일 정리 자동화 완성
💡
/save는 작업 내용을 커밋으로 기록하고 GitHub에 push합니다. 나중에 다시 열어도 어떤 작업을 했는지 추적할 수 있어요.
