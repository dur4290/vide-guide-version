Ch4. 실습 — 파일 정리 자동화

Chapter 4 ⏱ 약 60분

드디어 진짜 프로젝트를 만들 차례입니다! 🚀
다운로드 폴더 안에 파일이 섞여있어서 불편했던 경험이 있나요? 이번에 Claude와 함께 파일들을 확장자별로 자동 분류하는 Python 스크립트를 만들어봅니다.

💡
이번 챕터에서 만드는 것
스크립트를 실행하면 다운로드 폴더 안의 파일들이 자동으로 분류됩니다:
  • 📄 PDF → 문서/ 폴더
  • 🖼 이미지 (jpg, png 등) → 사진/ 폴더
  • 🎵 음악 (mp3 등) → 음악/ 폴더
  • 📦 그 외 → 기타/ 폴더

1. 실습 폴더 준비하기

1

워크스페이스 폴더 폴더를 VSCode로 열기

Ch3에서 클론한 워크스페이스 폴더 폴더가 닫혀있다면 파일 > 폴더 열기로 다시 열어주세요.

2

VSCode에서 Claude 열기

왼쪽 사이드바에서 Claude 아이콘을 클릭해서 패널을 여세요.

Claude가 워크스페이스 폴더 폴더를 인식하고 CLAUDE.md를 읽어들입니다.

2. Claude에 스크립트 만들어달라고 요청하기

코드를 알 필요 없어요 — 원하는 걸 말로 설명하면 됩니다!

1

첫 번째 요청 보내기

Claude 입력창에 아래 내용을 입력하세요 (그대로 복사해도 됩니다):

내 다운로드 폴더(C:\Users\사용자이름\Downloads)를 정리해주는 Python 스크립트를 만들어줘.

조건:
- PDF 파일은 '문서' 폴더로 이동
- 이미지 파일(jpg, jpeg, png, gif, webp)은 '사진' 폴더로 이동
- 음악 파일(mp3, wav, flac)은 '음악' 폴더로 이동
- 그 외 파일은 '기타' 폴더로 이동
- 폴더가 없으면 자동으로 만들어줘
- 각 줄에 주석으로 설명도 달아줘
⚠️
사용자이름 부분을 내 Windows 사용자 이름으로 바꾸세요. 모르면 Claude에게 "내 다운로드 폴더 경로 알려줘"라고 물어보세요.
2

생성된 코드 확인하기

Claude가 organize.py 같은 파일을 만들어줄 거예요. VSCode 왼쪽 파일 탐색기에서 확인해보세요.

Claude에게 이렇게 물어보세요: 
이 코드를 초보자도 이해할 수 있게 한 줄씩 설명해줘

3. 실제로 실행해보기

⚠️
실행 전 확인!
스크립트가 실행되면 파일이 실제로 이동됩니다. 먼저 테스트용 폴더로 연습해봅시다.
1

테스트 환경 만들기

Claude에게 이렇게 요청하세요:

바탕화면에 'test-downloads' 폴더를 만들고,
안에 테스트용 파일들(확장자만 다른 빈 파일 5개 정도)을 만들어줘.
그리고 스크립트가 그 폴더를 대상으로 실행되도록 경로를 바꿔줘.
2

스크립트 실행하기

Claude에게 이렇게 요청하세요:

organize.py를 실행해줘

Claude가 직접 실행해주고 결과를 알려줍니다. 테스트 폴더를 열어보면 파일들이 분류되어 있을 거예요! 🎉

오류 메시지를 복사해서 Claude에 붙여넣고 이렇게 물어보세요: 
이 오류가 났어. 왜 그런지 설명하고 고쳐줘:
[오류 메시지 붙여넣기]
