Ch1. 개발 환경 설정

Chapter 1 ⏱ 약 20~40분

이 챕터에서는 코딩에 필요한 프로그램 두 가지를 확인합니다. VSCode(코드 에디터)와 Python(프로그래밍 언어)입니다. 이미 설치되어 있다면 확인만 하고 넘어가면 됩니다.

1. VSCode 설치하기

VSCode는 코드를 작성하고 Claude Code와 대화하는 창입니다. 마이크로소프트에서 만든 무료 프로그램이에요.

1

VSCode 공식 사이트 접속

code.visualstudio.com으로 이동하세요.

💡
사이트가 자동으로 Windows용 다운로드 버튼을 보여줍니다. Download for Windows 버튼을 클릭하세요.
2

설치 파일 실행

다운로드된 VSCodeSetup-xxx.exe 파일을 더블클릭해서 실행하세요.

⚠️
설치 중간에 "PATH에 추가" 옵션이 나오면 반드시 체크하세요. 나중에 터미널에서 code 명령어를 쓸 수 있게 됩니다.
설치 진행 중 "추가 작업 선택" 단계에서 나옵니다. "PATH에 추가(다시 시작한 후 사용 가능)"에 체크하세요. 이 옵션이 없다면 기본 설정으로 진행해도 됩니다.
3

언어 설정 확인하기

VSCode는 영어로 사용해도 괜찮습니다. 이 가이드는 한국어 메뉴 이름을 함께 설명하지만, 영어 화면이어도 그대로 진행할 수 있어요.

💡
영어 화면이어도 정상입니다.
예를 들어 File은 파일, Terminal은 터미널과 같은 메뉴입니다. 교수자 화면도 영어일 수 있으니, 언어 설정은 맞추지 않아도 됩니다.
  1. 왼쪽에서 퍼즐 모양 아이콘(Extensions)을 클릭하세요
  2. 검색창에 Korean을 입력하세요
  3. Korean Language Pack for Visual Studio Code를 설치하세요
  4. VSCode를 재시작하면 한국어로 바뀝니다

2. Python 확인하고 필요할 때만 Anaconda 설치하기

Python은 우리가 만들 자동화 스크립트에 사용하는 프로그래밍 언어입니다. 데이터과학과 비즈니스프로그래밍1을 수강했다면 이미 Anaconda 또는 Python이 설치되어 있을 가능성이 높습니다. 먼저 설치 여부를 확인하고, 안 될 때만 설치하면 됩니다.

1

Python이 이미 설치되어 있는지 확인

VSCode에서 Terminal > New Terminal을 열고 아래 명령어를 입력하세요.

python --version

아래처럼 버전 번호까지 나오면 Python 설치 단계는 건너뛰어도 됩니다.

Python 3.x.x
⚠️
Python이라고만 나오면 아직 정상 연결이 아닙니다.
버전 번호가 없으면 Windows의 Python 실행 별칭이 잡혔거나, VSCode가 실제 Anaconda Python을 찾지 못한 상태일 수 있어요. 아래 힌트를 확인하세요.
Windows 시작 메뉴에서 Anaconda Prompt를 열고 python --version을 입력해보세요. 여기서 버전이 나오면 Python은 설치되어 있는 상태입니다. VSCode에서만 연결이 안 된 것이므로 다음 단계의 인터프리터 연결을 확인하면 됩니다.

이 경우는 성공이 아닙니다. 아래 순서대로 확인하세요.

  1. Windows 시작 메뉴에서 Anaconda Prompt를 여세요
  2. python --version을 입력하세요
  3. 버전 번호가 나오면 Anaconda는 설치되어 있고, VSCode 연결만 다시 잡으면 됩니다
  4. VSCode에서 Ctrl + Shift + P → Python: Select Interpreter를 선택하세요
  5. Anaconda Python 경로를 선택한 뒤 VSCode 터미널을 새로 열어 다시 확인하세요

그래도 안 되면 Windows 설정에서 앱 실행 별칭을 검색하고, python.exe와 python3.exe 별칭을 끈 뒤 다시 확인하세요.

2

필요한 경우에만 Anaconda 설치

앞 단계에서 Python 버전이 나오지 않았고, Anaconda Prompt도 없다면 Anaconda를 설치하세요. 이미 Python 버전이 확인됐다면 이 단계는 체크하고 넘어가도 됩니다.

설치가 필요한 경우 anaconda.com/download에 접속해서 Windows용 설치 파일을 다운로드하세요.

⚠️
"Register Anaconda3 as my default Python" 옵션은 체크 상태로 두세요.
3

VSCode에서 Python 연결 확인

마지막으로 VSCode 터미널에서 Python이 잘 연결되었는지 다시 확인합니다.

  1. VSCode를 열고 보기 > 터미널을 클릭하세요 (단축키: Ctrl + `)
  2. 터미널에 아래 명령어를 입력하고 Enter를 누르세요
python --version

아래처럼 버전 번호까지 나오면 성공입니다:

Python 3.x.x
⚠️
Python이라고만 나오고 버전 번호가 없으면 아직 성공이 아닙니다. 위의 python --version을 했는데 Python이라고만 나와요 힌트를 따라 연결을 다시 확인하세요.

Anaconda 설치 후 VSCode를 다시 시작해보세요.

그래도 안 된다면 시작 메뉴에서 Anaconda Prompt를 열고 거기서 python --version을 입력해보세요. Anaconda Prompt에서는 된다면 VSCode에서 Python 인터프리터 경로를 직접 지정해야 합니다.

  1. VSCode에서 Ctrl + Shift + P를 누르세요
  2. Python: Select Interpreter를 입력하고 클릭하세요
  3. 목록에서 Anaconda Python 경로를 선택하세요
  4. 일반적으로 C:\ProgramData\anaconda3\python.exe입니다

🎉 Ch1 완료!

VSCode와 Python이 준비됐어요. 이제 Claude Code를 설치할 차례입니다.
